# CityBitesFMS — Installation & Run Guide

## Prerequisites

- **JDK 11 or higher** must be installed and `javac` / `java` must be on your PATH.
  - Verify: open a terminal and run `javac -version`
  - Download: [Eclipse Adoptium](https://adoptium.net) or [Oracle JDK](https://www.oracle.com/java/technologies/downloads/)

---

## Option 1 — Command Line (javac + java)

### Step 1: Compile

Open a terminal in the project root (`CityBitesFMS/`) and run:

```cmd
javac -d build\classes -sourcepath src -encoding UTF-8 src\citybitesfms\Main.java
```

Or compile all files at once:

```cmd
for /r src %f in (*.java) do javac -d build\classes -sourcepath src -encoding UTF-8 "%f"
```

### Step 2: Copy image resources

```cmd
xcopy /Y /S "src\citybitesfms\resources\" "build\classes\citybitesfms\resources\"
```

### Step 3: Run

```cmd
java -cp build\classes citybitesfms.Main
```

---

## Option 2 — Apache Ant

If [Apache Ant](https://ant.apache.org/bindownload.cgi) is installed:

```cmd
ant run
```

Other useful targets:

| Command       | What it does                          |
|---------------|---------------------------------------|
| `ant compile` | Compile source files only             |
| `ant jar`     | Build a runnable JAR in `dist/`       |
| `ant run`     | Compile and run the application       |
| `ant clean`   | Delete `build/` and `dist/` folders   |

### Run the JAR (after `ant jar`):

```cmd
java -jar dist\CityBitesFMS.jar
```

---

## Option 3 — NetBeans IDE

1. Open NetBeans → **File > Open Project**
2. Select the `CityBitesFMS` folder
3. Press **F6** to run, or **Shift+F11** to clean and build first

## Food Images

Images must be placed in:

```
src\citybitesfms\resources\images\
build\classes\citybitesfms\resources\images\
```

Name each image `food_X.jpeg` where `X` matches the food item ID (1–21).

| ID | Item               | ID | Item                |
|----|--------------------|----|---------------------|
| 1  | Margherita Pizza   | 12 | Fish and Chips      |
| 2  | Pepperoni Pizza    | 13 | Fried Chicken       |
| 3  | BBQ Chicken Pizza  | 14 | Chicken Wings       |
| 4  | Classic Beef Burger| 15 | French Fries        |
| 5  | Cheese Burger      | 16 | Loaded Nachos       |
| 6  | Veggie Burger      | 17 | Red Wine (Glass)    |
| 7  | Tomato Soup        | 18 | White Wine (Glass)  |
| 8  | Mushroom Soup      | 19 | Chocolate Cake      |
| 9  | Chicken Alfredo    | 20 | Ice Cream Sundae    |
| 10 | Spaghetti Bolognese| 21 | Cheesecake          |
| 11 | Grilled Fish       |    |                     |

After adding images to `src/`, copy them to `build/classes/` using:

```cmd
xcopy /Y "src\citybitesfms\resources\images\*" "build\classes\citybitesfms\resources\images\"
```

## Project Structure

```
CityBitesFMS/
├── src/
│   └── citybitesfms/
│       ├── Main.java
│       ├── data/          (FoodDataStore, DataStore)
│       ├── model/         (FoodItem, CartItem, Order, OrderItem)
│       ├── ui/            (all screens and UI components)
│       └── resources/
│           └── images/    (food_1.jpeg ... food_21.jpeg)
├── build/
│   └── classes/           (compiled .class files + resources)
├── dist/
│   └── CityBitesFMS.jar   (generated by ant jar)
└── build.xml              (Ant build file)
```
